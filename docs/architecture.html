A voice call becomes a family memory graph

One narrator speaks; three Google AI models turn the call into durable, bi-temporal memory. Everything below the browser runs on Google Cloud.

Google AI models

Three, each doing one job

  • gemini-live-2.5-flash-native-audio — the call itself, duplex audio, us-central1
  • gemini-3.7-flash — story + fact extraction, contradiction judge, affect monitor, place resolver
  • veo-3.1-fast-generate-001 — story-card video, off the call path

Where the model is not

Retrieval is deterministic

  • BM25 lexical + 2-hop BFS + reciprocal rank fusion
  • No model in the read path, so the same question returns the same numbers every time
  • That reproducibility is what makes the working showable

Memory shape

Bi-temporal

  • valid_from/to — when it was true in her life
  • t_created/expired — when the archive believed it
  • A correction moves one clock, never both
